AsChecked

You built something with AI, and it works. AsChecked reads it and tells you, in plain words, what a professional would fix or add that you did not know to ask for.

Get it on GitHub Ask for a hand review

Why

Why a second pair of eyes

An AI builder does what you ask. It does not tell you what you forgot to ask for: who can read or delete other people's data, a key left in the code, a promise your project makes that the code does not keep.

People who build software for a living check these by habit. AsChecked puts that habit into a review anyone can run.

What it looks at

Your project checks

What you get

A short report you can act on

  • At most five findings, the most harmful first, each written as you would feel the problem.
  • For each one: why it matters, the evidence (a file and line, or the exact text), a fix with its effort, and a prompt you can paste straight to your AI builder.
  • Up to five further problems, one line each, with where they are.
  • What was not checked, and scans you can run yourself.

How it works

How it works

  1. Add it to the AI tool you already use.

    In Claude Code it is a skill. In a claude.ai chat you upload one file with your project.

  2. Answer three short questions,

    or say "skip": what it is and who uses it, what changed recently, and what is true today that the code would not show.

  3. Read the report.

    AsChecked is written only to read: it is told to install nothing, run none of your code and change no file.

The install steps are in the README.

Limits

What AsChecked is not

  • It is not an audit, a certificate or a security scan.
  • It never says your project is safe. It lists the problems it found in what it checked.
  • An AI model writes the report, so the result depends on the model you use. In our tests, weaker and free models missed serious problems.
  • It does not fix anything. You, or your AI builder, do.
  • It does not check each change before you merge. AsBuild does that.

Evidence

How it was tested

In a benchmark we ran AsChecked on four real projects in which earlier hand reviews had found 19 problems, with 13 model and effort settings, and scored every report without knowing which setting wrote it. We also ran AsChecked on 24 sample apps we built, 19 of them with problems planted on purpose. The testing page has every result, with each benchmark setting's score, cost and time.

It also reviewed our own AsBuild, and found two ways a pull request could have been reported as PROVEN when it should not have been. Both are fixed.

Tools

Which tools it works in

Tested in Claude Code. It also runs in a claude.ai chat, not yet proven to give the same results. For other AI tools, such as Codex, Cursor, Lovable and Bolt, it is packaged for, not yet proven: the tools page says what we tried in each and what happened.

Who it is for

Created for people who build with AI

For people who built an app, a site or an automation with an AI tool and are about to show it to real users, a client or an investor. You do not need to read code to use the report.
